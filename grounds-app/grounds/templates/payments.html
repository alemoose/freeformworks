How customers pay you
Setting up Stripe
  1. In Stripe, open Developers → API keys → Create restricted key. Allow Products: Write, Prices: Write, Payment Links: Write and Checkout Sessions: Read. Paste the key (it starts with rk_live_) above.
  2. Open Developers → Webhooks → Add endpoint and paste {{ stripe_hook }}. Choose the events checkout.session.completed and checkout.session.async_payment_succeeded.
  3. Copy the endpoint's signing secret (it starts with whsec_) into the webhook field above.
Setting up Square
  1. In the Square Developer Dashboard, open your application's Credentials (Production) and copy the access token into the key field above.
  2. Open Locations and copy the ID of the location that should receive the money.
  3. Open Webhooks → Add subscription, paste {{ square_hook }}, and choose payment.created and payment.updated. Copy its signature key into the webhook field above.

Without the webhook, invoices still work: use Check payments on the Invoices page to update them.
