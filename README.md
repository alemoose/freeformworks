# Freeform Works

Static site from Claude design export — **v1 (R5)**.

## Preview

```bash
python3 -m http.server 8080
```

Open http://localhost:8080

## Files

- `index.html` — from `Freeform Works · v1 (R5).html` in the zip
- `assets/` — logos, hero monitor, Lemoose screenshot

## R5 vs R4

R5 adds the interactive **What I build** section: tabbed mock previews (restaurants, barbers, photographers, florists, lawn care, retail) with a “What’s included” overlay per vertical.

## Before launch

- Add your Calendly URL on “Book a 15-min call” (currently `#` in contact)
- Compress large PNGs in `assets/` if needed
